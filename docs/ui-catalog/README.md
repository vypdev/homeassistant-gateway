# UI catalog screenshots

This directory contains screenshots generated from the Gateway Storybook catalog. They are implementation artifacts, not official Home Assistant references.

- Source: local Storybook at `http://127.0.0.1:6006`
- Browser: Chromium
- Viewport: `1280x720`
- Capture mode: Storybook iframe, 900 ms settle time
- Official references remain exclusively under `docs/ui-reference/home-assistant/screenshots/`

The current set covers button variants, cards, forms, operational layouts, settings, tabs, control matrix themes, foundations, icon buttons, sections, rows, columns, toolbars, metric cards, tags, form actions and dialogs.
